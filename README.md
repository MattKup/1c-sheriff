# 1C Sheriff — ИИ-агенты для 1С без утечки данных

**1C Sheriff** — локальный шлюз между 1С:Предприятие 8.3 и ИИ-агентами (ChatGPT/Codex, Claude Code, Cursor).
Вы задаёте вопрос о своей базе обычными словами и получаете точный ответ из регистров 1С.
Агент при этом видит не ФИО, названия контрагентов и реквизиты, а условные обозначения — токены.
Настоящие значения видите только вы, на своём компьютере.

[Сайт и пробный период](https://www.officeclan.ru) · Редакции «Чтение» и «Запись» · macOS (Apple Silicon и Intel), Windows — в разработке

## Что умеет

- **Отвечает на вопросы о базе 1С.** «Кто должен нам больше 100 000 ₽?», «Что пришло на склад сегодня?»,
  «Какие заказы не закрыты по этому клиенту?» — ответ собирается запросами к регистрам 1С, а не догадкой модели.
- **Скрывает чувствительные данные от агента.** ФИО, названия организаций, ИНН, банковские реквизиты, адреса,
  контакты, номера карт заменяются токенами до того, как данные уйдут агенту.
- **Показывает настоящие значения вам.** Переключатель «Вижу я / Видит агент» под каждым ответом и локальная
  панель «Линза» показывают те же строки с реальными названиями — только на вашем компьютере.
- **Ведёт к первоисточнику.** Из ответа можно открыть документы 1С, на которых он построен.
- **Честно говорит о неполноте.** Если строк больше, чем вернулось, ответ помечается как неполный.
- **Готовые проверки без ИИ:** платежи, долги и авансы, сверка актов, задачи и история проверок.

## Как это работает

```
Вы ── вопрос ──▶ ИИ-агент (Codex, Claude, Cursor)
                      │  вызывает инструменты 1C Sheriff (MCP)
                      ▼
              1C Sheriff на вашем компьютере
              • читает 1С через стандартный OData
              • заменяет защищаемые значения токенами
              • хранит словарь «токен ↔ значение» локально
                      │  только чтение
                      ▼
              1С:Предприятие 8.3 (опубликованный OData)
```

- **Локально.** Шлюз, словарь токенов и пароль базы — на вашем компьютере. Своих серверов, через которые
  проходят данные 1С, у Sheriff нет. Агент работает у своего поставщика по вашему договору с ним.
- **Без доработки 1С.** Не нужны расширения и изменения конфигурации: Sheriff читает стандартный интерфейс OData.
- **Только чтение в редакции «Чтение».** Провести, изменить или удалить документ через Sheriff нельзя.
  В редакции «Запись» агент готовит черновик, а создаётся он в 1С только после вашего подтверждения.
- **Правила маскирования под вашу базу.** Sheriff сам читает метаданные и предлагает, что скрывать;
  вы подтверждаете и при необходимости меняете правила.
- **Если вы сами вставили настоящее значение** в сообщение или приложили файл с реальными данными, сообщение
  уходит агенту, а Sheriff показывает под ним предупреждение: приватность этого сообщения не гарантируется.
  Решение остаётся за вами.

## Технические детали

- **MCP-сервер для ИИ-агентов.** Sheriff подключается к агенту по Model Context Protocol и даёт ему 15 инструментов,
  все только для чтения: `odata1c_bases`, `odata1c_info`, `odata1c_find_entity`, `odata1c_describe_entity`,
  `odata1c_query`, `odata1c_get`, `odata1c_raw_get`, `odata1c_batch`, `odata1c_recipe`, `odata1c_payments`,
  `odata1c_settlements`, `odata1c_check_result`, `odata1c_journal`, `odata1c_present`, `odata1c_reindex`.
- **Параллельное чтение.** `odata1c_batch` выполняет до 20 независимых запросов или рецептов за один вызов агента;
  по умолчанию 2 одновременно, для базы настраивается до 8. Агенту не нужно делать десятки ходов —
  меньше времени и меньше токенов.
- **Рецепты.** Готовые запросы к регистрам с параметрами (период, организация, склад) — агент вызывает рецепт
  по имени вместо того, чтобы собирать запрос с нуля.
- **Постраничное чтение без потерь.** Большие выборки читаются страницами (`has_more`, `next_skip`);
  каждый результат несёт признак полноты, и неполный итог не выдаётся за полный.
- **Токены.** Защищаемое значение превращается в устойчивый токен вида `[[org:ABCDEF1234]]`: один и тот же
  контрагент — один и тот же токен во всех ответах, поэтому агент может группировать и сравнивать, не видя имени.
- **Индекс метаданных.** При подключении базы Sheriff строит локальный индекс объектов и полей OData,
  по которому агент ищет нужные регистры и документы на обычном языке.
- **Стандартный OData 1С.** Подключение по адресу опубликованной базы (`…/odata/standard.odata`),
  пароль хранится в системной связке ключей.

## Для кого

- **Руководителю** — быстрые цифры по долгам, продажам, остаткам без ожидания отчёта.
- **Бухгалтеру** — ответы из регистров вместо ручных выгрузок в Excel.
- **ИТ-специалисту и администратору 1С** — один раз опубликовать OData и выдать пользователю права на чтение;
  дальше пользователи спрашивают сами.
- **Бухгалтерским фирмам** — работа с несколькими организациями (ИНН) в одной лицензии.

## Поддерживаемые конфигурации

Sheriff работает с любой конфигурацией, опубликованной через OData: агент находит нужные объекты по метаданным.
Для типовых конфигураций встроено **более 40 готовых рецептов** — проверенных запросов к регистрам:
Бухгалтерия предприятия, Управление торговлей (10 и 11), Управление нашей фирмой, Зарплата и управление персоналом.
Остатки, должники и кредиторы, продажи за день и за период, поступления и списания по банку и кассе и другое.
Sheriff сам определяет конфигурацию по метаданным и предлагает агенту только те рецепты, которые подходят к вашей базе.
Профиль Розницы — в разработке.

## Частые вопросы

**Видит ли ИИ мои данные?** Агент видит структуру и числа (суммы, количества, даты, номера документов),
а защищаемые значения — ФИО, названия, ИНН, реквизиты, адреса — только как токены. Настоящие значения
хранятся в локальном словаре на вашем компьютере.

**Может ли агент изменить данные в 1С?** В редакции «Чтение» — нет, доступ только на чтение.
В редакции «Запись» изменения создаются только после вашего подтверждения.

**Нужно ли дорабатывать конфигурацию 1С?** Нет. Нужен опубликованный OData и пользователь с правами на чтение.

**Гарантирует ли Sheriff, что ни одно чувствительное значение не уйдёт агенту?** Нет, и мы об этом прямо пишем:
маскирование работает по правилам, которые вы подтверждаете, а то, что вы сами вставите в сообщение, уходит как есть
с предупреждением. Подробно — в лицензионном соглашении, раздел «Данные и ответственность».

**Чем это отличается от выгрузки 1С в ChatGPT?** Выгрузка отдаёт модели все данные целиком, а считает модель «в уме».
Sheriff отдаёт агенту только нужные строки, без чувствительных значений, а суммы считает запросами к 1С.

### In English

1C Sheriff is a local MCP server and privacy gateway between 1C:Enterprise 8.3 (via standard OData) and AI agents
such as Codex (ChatGPT), Claude Code and Cursor. It gives the agent 15 read-only tools, 40+ built-in recipes for
standard 1C configurations and parallel batch reads (up to 20 queries per call), answers business questions from
1C registers, replaces personal and commercial values with stable tokens before they reach the agent, and shows
real values only to the owner on the local machine.
Read-only edition and a draft-writing edition with owner confirmation. macOS; Windows in development.
